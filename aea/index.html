综合成本函数 / 建议 v1，尚未实现

S04 已确认需要综合成本。建议从可解释的金额模型开始；归一化加权分只作备选，因为权重不易对应工时。完整工厂报价模型留待业务数据齐备后扩展。

利用率 η = Ause / Arect
C = q × [pm Arect + r / 60 × (tb Nb + tw Lw)]
材料成本 + 人工分钟单价 × 总秒数 / 60；成本越低越优。Arect = Ause / η，因此材料利用率已计入材料成本，不再额外重复惩罚 η。

四个可调参数

  • pm：材料单价，货币 / m²；随材料和厚度配置。
  • r：人工综合单价，货币 / 分钟。
  • tb：每刀平均时间，秒 / 刀。
  • tw：每米焊接平均时间，秒 / m。

四项无生产默认承诺。集中配置并冻结到案件；以实际工时调整 t，以真实价格调整 p/r。避免同时任意调所有项。

固定的计算口径

N 是业务折弯刀数，L 是去重后的适用焊接长度。q 是该工件数量；不同工件逐项求和。面积先换 m²、长度换 m；数量为正整数，成本参数有限且非负，面积为正且利用率满足 0 < η ≤ 1，异常数据不能参与正式排名。利用率为“面积之和的比”，不平均各件百分比。

同一候选和阶段计算 Ause、Arect。矩形为每件独立矩形面积之和，不是摆图后的整体 bbox。Q-02 的白线/绿线与扣孔口径未定前不进入正式排序。

手算示例，仅为公式演示：设 p=80、r=1.5、tb=12、tw=90、q=1。方案 A 使用面积 1 m²、矩形 1.25 m²、8 刀、焊 0.6 m：利用率 80%，材料 100，人工 3.75，总计 103.75。方案 B 使用面积 1 m²、矩形 1.15 m²、12 刀、焊 1 m：利用率约 87.0%，材料 92，人工 5.85，总计 97.85。材料节省可抵消更多人工，是否合适由实际参数决定。

排序前置：必须通过适用几何/制造检查；缺值、无效面积或尚未制造复算的值明确标记估计/未知，不能用 0 获胜。理论阶段用于搜索预估，最终候选用同一冻结配置复算再排名；失败或没有改善保留原基线。

边界：v1 是搜索成本代理，尚不计刨槽额外工时、换刀/装夹、激光切割、机器费、整板取整与组合套料，也不是客户报价。刨槽较多的方案可能因此低估；先报告未计项，在工厂数据齐备后按同样单位扩展，不能称为“工厂真实总成本最优”。

04 / 最容易混淆的面积和次数

以下是建议拆开的数据口径，不替你确定行业定义。只有确认计算对象、阶段、单位和汇总方式后，数值才适合用于计价。

实际展开面积

我的候选理解：最终制造切割轮廓围成的净板料面积，孔洞是否扣除须确认。当前 UsableArea 取折焊轮廓外环面积减内环面积，不是直接从最终白色净轮廓计算。

候选口径：Σ（最终外轮廓面积 − 孔洞面积）

源蒙皮面积、理论展开面积、制造净面积、计价面积分别存储；不预设它们相等。

最小外接矩形面积

需确定围的是白色切割线，还是白线与绿色外尺寸参考线的并集；是每件独立算，还是某个组合开料组。当前代码取每件 TrimmedLoops + Outlines，再汇总面积。

当前：Σ 各件旋转包围矩形面积

曲线采用采样求矩形，不能自动称为数学意义的精确全局最小；工件最大长和最大宽也不一定来自同一件。

开料面积

你同时提出「标准开料长宽」，因此需要区分：单件矩形毛料、组合开料矩形、标准整板耗用面积，以及按某一边规格取整的计价面积。

具体计算规则待确认，当前不填公式

现有 BlankArea 实际来自单件最小矩形；没有标准板规格就不能声称算出了标准板耗用量。

折边面面积

可能指满足高度条件的整块折边面，也可能是用于免计价的局部折边带。当前实现读取正折 / 反折豁免带面积，并从可用面积中扣除。

当前：计价面积 = UsableArea − 适用豁免带

「完整折边面」与「豁免带」不直接等价。当前默认仅扣正折，与你的口径是否一致待确认。

折弯刀数 / 焊接次数 / 刨槽次数

线段数、连续工艺线数量、机器实际动作次数、计价次数可能不同。当前折弯刀数有组内几何线归并；刨槽次数按最终刨槽折弯记录计数；焊缝记录数不能直接称为实际焊接操作次数。

需要明确同一直线上分段、孔洞打断、重复走刀、分次加工和多件重复数量如何计数。

长度 / 超长超宽 / 板型

焊接长度应明确统计实际接缝、中心线还是红色偏移线，并避免跨件重复。超限必须绑定可用板规格与允许旋转规则；最低弧度与多孔板阈值都需要业务定义。

超长超宽当前按你列出的「输出标志」保留，暂不擅自升级成强制分件或拒绝出图。

05 / 参数长期设置，案件按需覆盖

建议把设置界面与求解服务分开。用户维护一套默认配置，建案时选择并冻结版本；AI 调用当前案件的已生效配置。

建议的参数来源顺序

  1. 系统初始默认：安装时可用的基础值与资源。
  2. 用户 / 工厂默认方案：长期保存的计价规则、系数表和刀具集合。
  3. 本案件覆盖：只填与默认不同的值，显示覆盖来源。
  4. 冻结快照：保存本次实际值、表版本与刀具哈希，所有结果绑定此版本。

第 2 层完整用户配置管理是已要求、尚待实现的能力。现有项目参数快照和刀具冻结能力可以复用。模型属性若也保存参数，需要明示优先级，不能静默覆盖面板值。

结构化资源怎样管理

  • 折弯表：按板厚、正反折与角度范围编辑；显示角度定义、单位和每侧缩进语义，检查缺档与重叠。
  • 刀具库：导入、缩略预览、单位 / 坐标 / 刀尖朝向检查；每把刀有 ID、版本与适用条件。沿用当前刀具用途与几何约定；支持工厂全部有效刀具，任一能直接折弯即可。
  • 刨槽系数：作为工程配置显式保存；按 S07 保留当前缩进语义与 1.0 默认，增加校验、版本和快照，先不改算法。

DSH 插件内的独立设置控件。板厚、材料、数量可直接设置；计价、折弯表与工厂刀具库由插件长期管理，案件冻结生效版本。Rhino AEASetting 作为现有兼容入口。

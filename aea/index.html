综合成本函数 / 建议 v1，尚未实现

S04 已确认需要综合成本。建议从可解释的金额模型开始；归一化加权分只作备选，因为权重不易对应工时。完整工厂报价模型留待业务数据齐备后扩展。

利用率 η = Ause / Arect
C = q × [pm Arect + r / 60 × (tb Nb + tw Lw)]
材料成本 + 人工分钟单价 × 总秒数 / 60；成本越低越优。Arect = Ause / η，因此材料利用率已计入材料成本，不再额外重复惩罚 η。

四个可调参数

  • pm：材料单价，货币 / m²；随材料和厚度配置。
  • r：人工综合单价，货币 / 分钟。
  • tb：每刀平均时间，秒 / 刀。
  • tw：每米焊接平均时间，秒 / m。

四项无生产默认承诺。集中配置并冻结到案件；以实际工时调整 t，以真实价格调整 p/r。避免同时任意调所有项。

固定的计算口径

N 是业务折弯刀数，L 是去重后的适用焊接长度。q 是该工件数量；不同工件逐项求和。面积先换 m²、长度换 m；数量为正整数，成本参数有限且非负，面积为正且利用率满足 0 < η ≤ 1，异常数据不能参与正式排名。利用率为“面积之和的比”，不平均各件百分比。

同一候选和阶段计算 Ause、Arect。矩形为每件独立矩形面积之和，不是摆图后的整体 bbox。Q-02 已确认白线范围与扣孔口径，相关面积和白线利用率已实现；工序计数与长度已由Q-06确认；正式排序仍需 Q-11 成本参数和金额公式，不把已确认面积重新列为阻塞。

手算示例，仅为公式演示：设 p=80、r=1.5、tb=12、tw=90、q=1。方案 A 使用面积 1 m²、矩形 1.25 m²、8 刀、焊 0.6 m：利用率 80%，材料 100，人工 3.75，总计 103.75。方案 B 使用面积 1 m²、矩形 1.15 m²、12 刀、焊 1 m：利用率约 87.0%，材料 92，人工 5.85，总计 97.85。材料节省可抵消更多人工，是否合适由实际参数决定。

排序前置：必须通过适用几何/制造检查；缺值、无效面积或尚未制造复算的值明确标记估计/未知，不能用 0 获胜。理论阶段用于搜索预估，最终候选用同一冻结配置复算再排名；失败或没有改善保留原基线。

边界：v1 是搜索成本代理，尚不计刨槽额外工时、换刀/装夹、激光切割、机器费、整板取整与组合套料，也不是客户报价。刨槽较多的方案可能因此低估；先报告未计项，在工厂数据齐备后按同样单位扩展，不能称为“工厂真实总成本最优”。

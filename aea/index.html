利用率 η = Ause / Arect
C = q × [pm Arect + r / 60 × (tb Nb + tw Lw)]
材料成本 + 人工分钟单价 × 总秒数 / 60；成本越低越优。Arect = Ause / η，因此材料利用率已计入材料成本，不再额外重复惩罚 η。
